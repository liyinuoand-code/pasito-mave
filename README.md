# Pasito · 我的 MAVE 西语词库

网站地址：https://liyinuoand-code.github.io/pasito-mave/

Pasito 是一个长期使用、由自己决定学习节奏的私人学习记录空间，网页同时公开提供 **MAVE（视觉艺术与教育硕士）专业词库**和 **DELE B1/B2 难度练习词库**。

## 我的专属词库

- 不设固定的六周课程或学习阶段；自选的每日背词目标会按当地午夜自动结算，未完成的部分依用户要求计入逾期。
- 「我的词库」直接展示 MAVE 专业词、DELE B1、DELE B2 和全部词汇的数量，并提供入口到完整可搜索词库。
- 可以打开「我收藏的单词」，或随时进行单词卡、选择/拼写小测验、听力练习。
- 专业词库不会被移除：MAVE 艺术教育硕士课程相关术语、课堂表达与中文解释会继续更新；其他分级词库也同时保留。
- 单词总量不设人为上限。新内容在现有 `window.MAVE_WORDS` 中去重追加，旧词编号不可改动。

## 自选每日背词任务与逾期顺延

- 在 **我的词库** 页面选择每日数量及 MAVE/B1/B2/全部词汇。可选快捷数字，也可输入任意正整数；词库没有人为总量上限。
- **所有每日结算都按 `Europe/Madrid`（巴塞罗那当地时间）的自然日，以凌晨 `00:00` 为分界**。它会自动适应冬令时和夏令时，不取决于电脑的时区设置（但需要设备时钟准确）。
- 每天的目标和学习分类按日期存入 `dailyTasks`。午夜过去后，该日未完成的数量标记为 **逾期**，保留在第二天和之后的逾期清单；新一天的目标另行产生，**不会覆盖原来的欠数**。
- 系统从用户首次打开含有逾期功能的新版网页开始建档，不根据缺少每日目标记录的旧日期**猜造历史逾期**。已有当日背词日志自动用于计算当日完成量。
- 如果连续几天没打开网页，再次打开时也会补建这段时间内的每日任务，并计算累计逾期数量。注意：这可能使逾期数量逐日增加。
- 每日学习**先复习最多 20 个旧词，再按照今天设定的数量安排真正未学过的新词**。历史逾期任务继续保留独立记录，但**不会阻止或占用今天的新词抽取**。新词每日完成数独立按该日首次学习的记录计算；旧词复习不占新词名额。
- 当天修改词数或词库类别，只调整**当天**的任务；昨天和更早的逾期任务不会被改变。
- 首页显示 **今日新词进度、历史逾期待补、旧词复习统计和全词库剩余真正未学词数量**。只需要点「开始 / 继续每日学习」，就会自动完成复习 → 新词的顺序。
- 小测验与词卡都可记录学习；听力、课堂随手记以及独立打卡仍属于**可选功能**，不会自动积累为逾期任务。
- 如果选定类别里的未学词不足，网站会自动从其他类别挑选尚未学过的词；如果整个词库都已学习过，会明确提示真实的新词库存为 0，**不会把旧词重新冒充新词**。没有词可学习时，剩余每日目标和逾期记录都不会被删除。

## MAVE 课堂概念库（持续更新）

- 网站左侧 **「概念库」** 已变为可搜索、可持续追加的概念档案，与普通单词库互不覆盖。
- 每个概念包括西语名称、中文解释、通俗说明、辅助理解的中西语问题、**课程日期、授课老师、课程名称和材料来源**。
- 支持按 **日期、资料来源、老师／课程** 筛选，同时支持西语与中文关键词搜索。新概念会以来源日期排序，现有概念保留独立 `id`，不在更新时覆盖旧内容。
- 必须区分 **真实课堂笔记的归纳**、**课程教学大纲**、**课前预习材料及教学改写**；不得将预习内容或自行设计的问题声称为老师课堂原话。
- 早期版本从 8 个概念补充到 17 个；2026-10-14 的真实课堂转写再增加 14 个，当前共 31 个概念。**10 月 14 日条目标为大纲／预习，不代表当日课程已经实际讲过这些内容**。
- 以后用户提供每天的课堂笔记、整理文本或可合法使用的教学资料时，ChatGPT 会在得到该批材料后按**老师、课程、日期**提取并去重追加概念；不会仅因为日历翻到新的一天就自动生成、抓取或编造“今日课堂笔记”。
- 「概念库」没有强制每日完成任务，也**不会**自动加入词汇任务的逾期统计。原来的打卡、收藏、单词复习与逾期功能保持不变。

## 一键每日学习：先复习 20 个，再自动进入新词

- 首页和「背单词 → 单词卡」只有一个主要入口：**「开始 / 继续每日学习」**。不需要自行点击两个学习模块。
- 每次打开当日学习时，自动先复习**最多 20 个已经学过的旧词**；全部做完时**自动切换到当日新词**，不需要再点一次「开始」。
- 复习使用所有历史学过的词，包括 MAVE 和 B1/B2，优先挑选过去**复习次数较少、上次复习较早**的词，在同等条件下随机，尽量避免连续两天重复。历史已学词不足 20 个时，只复习现有数量，然后直接进入新词；没有旧词时直接开始新词。
- **复习名单按巴塞罗那当天日期固定保存**在 `reviewPlans`。在第 12 个词关闭网页再打开，会继续剩下的 8 个，不重新随机，已完成的复习不会再弹出。
- 学习页和首页展示小进度框：**历史已学总数**、**今天已复习多少旧词**、**旧词待复习多少**（历史旧词中今天还未复习的数量；不等同于间隔重复系统的到期数）。
- 旧词复习单独保存在 `reviewLogs`，不会增加今日新词任务完成数，也不会导致已学过的词当成新词；原有熟悉度三分类和间隔复习日期继续更新。
- 新词每日目标仍在「我的词库」自选，巴塞罗那时间 00:00 结算，未完成的新词任务继续按原来的规则记录为逾期。学习过的新词不会因为改版而被重新编号或标记为未学。
- 单词卡仍有「额外复习」「智能混合」「完整词库」等可选功能，但不影响一键每日学习；额外复习也没有总数量上限。
- 为每天的新词保存独立的选词计划 `dailyNewPlans`：在第 5 个新词退出后重新打开，将继续同一批尚未学的新词，不会重新随机抽到旧词。既有学习记录没有此字段时自动兼容。
- 当某个类别新词用完但其他类别还有未学词时，会按原类别优先、其余类别补足的方式安排每日新词，不再出现「自由新词列表有词、每日学习却空白」的问题。每天的新词计数独立于历史逾期账本。
- **小测验可自选题数**，设置保存在 `settings.quizCount`，默认 10；题数没有人为固定上限，但不能超过当前类别可用词量。
- 旧备份兼容：保留原来的 `mave_espanol_atlas_v1` 本地存储键和 `mave-atlas-backup-v1` 备份格式，仅补充 `reviewPlans`、`dailyNewPlans` 和首次学习日期的可选元数据，**不删除旧词、旧复习、收藏、打卡、笔记或逾期数据**。
- 网站继续沿用低饱和灰粉与暖灰主题。

## 错题本：答错自动收录 · 自己勾选掌握

- 主导航新增 **「错题本」**；首页和「我的词库」也有快捷入口。沿用低饱和灰粉配色，支持手机浏览。
- 当单词卡选 **「① 忘记了」**，或选择题/拼写小测验**答错一次**，该单词立刻自动进入错题本，累计错误次数 +1，并记录最近出错日期。单词卡选 **「② 有点模糊」** 不会被当作一次明确错误。
- 每个错词展示西班牙语单词、中文释义、例句（西语／有数据时附中文）、来源主题、历史错误次数及最近出错时间，支持搜索、听单词和听例句。
- 通过 **「待掌握」「已掌握」「全部错题」** 筛选；只有用户自己点击词条旁的 **「✓ 标记已掌握」**，状态才切换为已掌握。答对一次不会自动从错题本移除。已掌握后依然保留历史记录和累计错误次数，可撤销掌握。
- **「练习待掌握错词」** 可以直接用现有单词卡复习错题。未掌握的错词优先进入日后的每日随机旧词复习；**勾选已掌握后恢复一般随机复习**（不会被删除或排除）。如果已掌握的词再次答错，自动恢复待掌握状态，同时再次累计错误次数。
- 错词存储在原有本地进度 `mave_espanol_atlas_v1` 的新增 `mistakes` 字段中，随原来的 `mave-atlas-backup-v1` JSON 备份一同导出和导入。收藏、打卡、阅读笔记、复习进度、每日任务、课程词库内容均不会被覆盖。
- 从旧版本升级时，可以把旧数据中**最后一次学习评级为「忘记了」**的单词保守补录为一次错误；旧版本没有逐词保存全部历史错误，不能准确重建所有早期错误次数，因此不臆造旧记录。
- 错题本不增加每日新词数量；练习旧词也不会当成新词计入目标。学习记录仍然只存放在当前浏览器；使用新设备前应导出备份。

## 进度保存、隐私与备份

- 网站沿用浏览器本地存储键 `mave_espanol_atlas_v1`，兼容此前的打卡、复习、收藏、笔记与每日参考数量记录。
- 数据仅保存在当前浏览器，不会自动在多设备之间同步。清除浏览器数据或切换设备前，在网站设置里使用「导出备份」保存 JSON 文件。
- GitHub 仓库及网站内容为**公开**；不要上传个人身份资料、私密笔记或未授权的课堂录音。

## 后续更新方式

将课堂材料提供给 ChatGPT，提出「更新 Pasito」即可请求同时**更新单词词库与课堂概念库**。更新概念时标明课程日期、老师、来源和是否为预习推断；更新词汇时核对旧词 ID、浏览器存储键、分类数量、背词和逾期功能。每次改动后应验证搜索、来源筛选、打卡与导入／导出备份功能。
