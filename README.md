# Pasito · MAVE 西语学习空间

访问网站：https://liyinuoand-code.github.io/pasito-mave/

这个静态网站用于学习 MAVE 专业西语词汇和 DELE B1/B2 难度分组词汇。

## 词库维护规则

- **不设置词库总数量上限**：`index.html` 中的 `window.MAVE_WORDS` 是全量词库，所有词条均可在“完整词库”中按分类和关键词筛选；导航数量由实际词条数量自动计算。
- 每次更新只追加去重后的新词，**保留旧词的 `id` 和内容**。新词使用新的唯一 `id`，避免损坏既有背词进度。
- 单次小测验抽取 10 题，**并不限制词库容量**；记忆卡可以覆盖所选分类内的所有词。
- 词库可以持续增长；但浏览器性能、网页下载速度和 GitHub 文件大小都存在现实限制。词库显著增大时可优化分批加载，但不会设置固定词数上限。

## 自定义每日学习计划

- 在网站的**学习计划**页面，输入每天希望学习的词条数量（至少 1 个，不设置固定上限），还可选择 MAVE、DELE B1、DELE B2 或全部词库。
- 可以直接选择 5、10、15、20、30、50 个快捷目标，也可输入自己的数字。保存后首页同步显示 **今日已学 / 今日目标** 和剩余词数。
- 点击首页 **开始今日计划**，系统按已学过的数量扣除今天需要完成的词卡，并保留复习进度。完成后仍可以切换“智能混合”自由学习。
- 词卡上选择“忘记了 / 有点模糊 / 记住了”即计入当天练习，不要求手抄单词；听力与课后笔记都是可选项。
- 本地存储沿用 `mave_espanol_atlas_v1`，保留旧记录；`settings.planCategory` 为空的旧备份默认按全部词库统计。
- 六周路线只是学习主题建议，不规定每天固定背多少个词。

## 学习进度与备份

浏览器本地存储键为 `mave_espanol_atlas_v1`。更新代码时请勿更改这个键、旧单词 ID 或备份格式。

在重大更新或更换设备之前，进入 Pasito 设置页点击**导出备份**。目前学习进度仅保存在当前浏览器，**没有跨设备自动同步**；清除浏览器数据可能丢失进度。

## 更新流程

1. 提供新课堂笔记或可合法使用的教学材料。
2. 比对已存在的词条并去重，标记课堂原始材料与学习改写例句的来源。
3. 追加新词，保留旧词及其 ID，不修改当前浏览器存储格式。
4. 检查完整词库数量、分类数量、卡片学习、练习和本地备份功能，再发布至 `main`。
